# ribbilator

a slow ticker on my GitHub contribution graph: one column of the word per week, and each day a little script decides whether that day's cell lights up :and that's all it does. ribbit

lit cells don't try to be the darkest forest on the graph. they only have to stand out against the days around them--with some randomness on top, so the letters get a bit of depth instead of looking stamped on

my real commits show through the pattern, and that's the point.. it's a joke, not a productivity claim :)

MIT licensed: take it, change it, and make your own graph croak
